Generated by `examples/admission-slack/report.py` from the JSON pair
records; do not edit by hand. Each run is one suite under one deployment
configuration, replayed over the suite's own reference plans
(AgentDojo `ground_truth`) with a real `ToolCallGovernor`. No model is in
the loop, so these are facts about the monitor's admission behaviour on
the reference plans — not about what an agent would emit, and not an
upper bound on utility over all ways of solving a task.

*forced & executable* = the substitution has the **same projection** as the
original (so Theorem 2 forces the same verdict), was **admitted**, and the
tool **really executed it** on a fork of the environment. *referential* is
the subset where the substituted value names another record of the same
kind in the environment (same structural slot), i.e. the admitted call acts
on a different object rather than carrying different payload text.

The referential requirement is part of the **definition** of the measured
quantity, not a post-hoc cleanup: without it the count is dominated by
same-shape values that are not records of anything. In the ROPE comparison
dropping it turns 18 pairs into 69, of which 45 have candidates like `I`,
`a`, `an`, `and`, `as`, `did`, `for` — tokens of the request.
